# MarketPulse — analytics UI prototype

An original, interactive market data operations mockup based on the supplied resume. All data is synthetic. It does not connect to Bloomberg, an exchange, or any backend.

## Run

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. `npm run build` checks TypeScript and creates `dist/`; `npm run preview` serves the build.

## Review the workflows

- **Overview / Live feeds:** chart metric and time windows, simulated updates with pause/resume, search, region/status filters, latency sorting, pagination, feed detail drawer, and CSV export.
- **Alert center:** acknowledge alerts and inspect affected exchanges. Acknowledgement does not resolve feed health.
- **Configuration:** create/edit threshold rules, enable/disable, inspect versions. Switch to Admin using the profile role selector to try rollback.
- **Audit trail:** search events and inspect before/after diffs generated by rule and alert actions.
- **Appearance:** light/dark theme and responsive navigation.

The user selector previews viewer/operator/admin UI permissions only. It is not authentication or a security boundary. Changes live in memory and reset on refresh. Rule configuration does not evaluate the synthetic data stream. Chart comparison data and KPI changes are illustrative. Google's DM Sans font is optional; local fonts provide a fallback.

## Structure

- `src/App.tsx`: application shell and interactive workflows.
- `src/data.ts`: typed synthetic fixtures and data helpers.
- `src/Charts.tsx`: Chart.js plots and small trend visualizations.
- `src/styles.css`: responsive tokens and component styling.
- `DESIGN.md`: visual direction and next implementation phase.

This phase deliberately establishes the UI for review. The next phase can introduce Redux Toolkit, Express APIs, MongoDB/Mongoose persistence, Socket.IO streaming, server-enforced JWT/RBAC, and automated integration tests before production deployment or real feed integrations.
